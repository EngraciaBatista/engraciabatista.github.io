About Me

Making AI Measurable, Reliable and Safe

Hi there! I'm Engracia, an NLP Engineer who builds and evaluates LLM systems for production software. One question drives my work: how do we know an AI system is actually working?

At memoQ, I work on evaluation frameworks for LLM output, multi-agent LLM systems that make AI judgements more reliable and traceable, and defences that harden LLM pipelines against prompt injection.

My path here is not a straight line, and that is my advantage. My first degree is in Fine Arts. I then spent 15+ years as a Project Manager and Business Analyst, founded Arrow Data Specialists, and moved into data science, BI and machine learning. So I am as comfortable with stakeholders and customers as I am with code: turning vague needs into clear requirements, success criteria and evaluation plans.

What I'm focused on next: applied AI engineering, where LLM evaluation, AI security and agentic systems matter, helping teams and customers put AI to work with confidence.

Outside work, I volunteer with the PMI (Project Management Institute) community, where my Mentoring Program won PMI-DF Project of the Year 2024, and I'm completing a Software Engineering Technology diploma at Centennial College.

Claude Tutoring Skill

Open sourceMulti-agentClaude Code pluginAI for learning

A Claude skill and plugin that turns Claude into a coding tutor instead of a code generator, for people who need to understand, explain and defend the code they work with.

Build mode teaches while the work gets done, at three levels: a Socratic loop where you write the code, a quiz after each unit Claude builds, or a fast build with a standup-ready recap.

Explore mode is an orchestrator–worker multi-agent system for code you didn't write. Explorer agents map the codebase once, six specialist agents draw UML diagrams in parallel (component, class, sequence, activity, ER, state), and the orchestrator verifies every element against real file and line locations before showing it. Read-only subagents, the right model per job, and incremental updates keep it cheap on large repos.
